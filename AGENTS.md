# OMP Harness

Этот репозиторий содержит инструкции для OMP. Читайте `README.md` для подключения и `docs/WORKFLOW.md` для пояснения планов и Git staging.

- Общие правила для других проектов лежат в `global/AGENTS.md`; правьте их вместе с описанием поведения в `docs/WORKFLOW.md`, не смешивайте с правилами этого репозитория.
- Не изменяйте пользовательскую конфигурацию и существующий `~/.omp/agent/AGENTS.md` без явного запроса. Не коммитьте auth, сессии, логи, кэши и машинное состояние.
- После правок проверьте читаемость инструкций в OMP, `git diff --check` и `git status --short`. Не утверждайте, что непроведённые проверки прошли.
